Continuous Oblique Imagery POC v0.8
===================================

Purpose of v0.8
---------------
Keep the validated continuous-sequence logic from v0.7 and replace the weak structure-crop projection with a footprint-constrained homography model.

Important product rule
----------------------
Span visibility is QA metadata only. Images are NOT removed because a complete span or both structures are not visible.
Sequence membership is still decided by circuit-run geometry / pass direction / AOI logic. DINO remains QA-only.

Structure-crop model
--------------------
1. The four DXF footprint vertices are associated with image TL/TR/BR/BL using EO OPK.
2. A projective homography maps ground XY directly to image pixels.
3. Structure base XY is projected through the homography.
4. Structure top is projected by extending the camera->top ray to the local base-Z plane, then mapping that ground intercept through the same homography.
5. If homography construction fails, v0.7 approximate OPK/FOV projection remains as an explicit fallback.

This is footprint-constrained projection, not a full lens-distortion-aware camera calibration.

Windows / PyTorch
-----------------
The tested Windows CPU combination is:
  torch 2.6.0+cpu
  torchvision 0.21.0+cpu

If rebuilding the environment, install the CPU wheels explicitly:

  python -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cpu

Then install the remaining dependencies as required.
