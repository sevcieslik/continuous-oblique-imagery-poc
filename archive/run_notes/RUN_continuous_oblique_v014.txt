Continuous Oblique POC v0.14

Purpose of v0.14
----------------
Keep the validated continuous-163 sequence logic unchanged and tighten only structure-crop detection.

Grounding DINO no longer searches the full source image. For each candidate structure:
1. LiDAR + EO + footprint camera geometry predicts a source-pixel position.
2. A local ROI is built around that geometry prior.
3. Grounding DINO runs only on source-resolution tiles contained inside the union of those local ROIs.
4. Detections are filtered against both full-image scale and local-ROI scale.
5. A structure can only use detections whose centres fall inside its own ROI.
6. The final assignment score gives materially more weight to distance from the predicted structure position.
7. If no acceptable tower is found, no crop is written for that observation.

No structure-crop failure removes, relabels, or otherwise changes an image in the legal continuous 163 sequence.

QA colours
----------
Cyan rectangle : local geometry-derived detector ROI. Grounding DINO does not see pixels outside it.
White cross    : geometry prior for the target structure.
Dim magenta    : raw Grounding DINO detections inside this structure ROI.
Bright magenta : detections that passed plausibility filtering.
Blue/cyan circle: local geometry-association gate around the structure prior.
Orange box     : source-resolution detector tile that produced the selected detection.
Green box      : selected visual tower detection assigned to this structure_id.
White box      : final crop extent.

Expected status examples
------------------------
OK_VISUAL_DETECTION
NO_PLAUSIBLE_DETECTIONS_IN_ROI
NO_DETECTION_IN_GEOMETRY_GATE
NO_GEOMETRY_PRIOR
NO_VISUAL_DETECTION

What to inspect after the smoke run
-----------------------------------
1. qa\structure_detection
   - there should be no magenta detections outside the cyan ROI for the structure being reviewed;
   - the green selected box should land on the intended lattice tower;
   - the white crop should contain the complete structure with useful context.

2. structure_crops
   - only accepted visual detections are written;
   - missing detections are allowed and do not affect 163 continuity.

3. Console summary
   - should report:
       Tower search mode: LOCAL_GEOMETRY_ROI
   - product sequence counts should remain consistent with the previous validated run.

Tuning only if required
-----------------------
If the correct tower sits just outside the cyan ROI:
  --tower-roi-radius-fraction 0.20
or:
  --tower-roi-max-radius 4200

If the correct tower is inside the ROI but rejected by the local gate:
  --tower-gate-fraction 0.38

If oversized field/background boxes still survive:
  --tower-max-roi-area-fraction 0.25
  --tower-max-roi-width-fraction 0.70

Do not use --tower-allow-no-prior for v0.14. It is retained only for CLI compatibility; v0.14 intentionally has no full-image detector fallback.
