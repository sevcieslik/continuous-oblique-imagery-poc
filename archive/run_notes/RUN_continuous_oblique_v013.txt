Continuous Oblique POC v0.13

Purpose of v0.13
----------------
Reduce Grounding DINO false positives without changing the continuous 163 sequence.
The detector still scans the full source image in overlapping tiles, but structure crops now use:
1. global NMS;
2. bbox plausibility filtering;
3. geometry-gated assignment to a specific structure_id;
4. a minimum combined detector/geometry assignment score;
5. one-to-one assignment between structures and detections.

No crop failure removes an image from the legal continuous 163 sequence.

QA colours
----------
Dim magenta : raw merged Grounding DINO detections, including rejected false positives
Bright magenta: detections that passed bbox plausibility filtering
Cyan circle : geometry-association gate around the structure prior
White cross : geometry prior
Orange box : source tile that produced the selected detection
Green box  : selected visual tower detection assigned to this structure_id
White box  : final crop extent

Expected status examples
------------------------
OK_VISUAL_DETECTION
NO_PLAUSIBLE_DETECTIONS
NO_DETECTION_IN_GEOMETRY_GATE
NO_GEOMETRY_PRIOR
NO_VISUAL_DETECTION

Tuning only if required after looking at QA
-------------------------------------------
If correct towers are being rejected because the geometry prior is offset:
  --tower-gate-fraction 0.22

If too many huge field/background boxes survive:
  --tower-max-area-fraction 0.025
  --tower-max-width-fraction 0.12

If correct detections are present but assignment is too conservative:
  --tower-min-assignment-score 0.20

Do not use --tower-allow-no-prior for the first validation run. It exists only for diagnostic cases where no usable geometry prior can be built.
