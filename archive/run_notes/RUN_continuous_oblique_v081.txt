Continuous Oblique Imagery POC v0.8.1
=====================================

Purpose of v0.8.1
-----------------
Keep the validated sequence / DINO logic from v0.8 and correct the structure-projection math revealed by the v0.8 QA images.

What was wrong in v0.8
----------------------
The footprint homography was treated inconsistently:
- structure base XY was mapped directly through H;
- structure top was projected to a different plane (base_z) before H.

A homography represents one reference plane. Mixing planes creates along-view offsets in oblique imagery, especially where ground elevation varies.

v0.8.1 correction
-----------------
1. Build the footprint homography using one reference plane Z (optical-target/local ground Z).
2. Project BOTH the 3-D structure base and 3-D structure top along their camera rays to that SAME reference plane.
3. Apply the same homography H to both ray-plane intercepts.
4. Build the crop from the resulting base/top pixels.
5. Keep the old approximate OPK/FOV model only as an explicit fallback.

This remains footprint-constrained projection, not a full distortion-aware camera calibration.

Important product rule
----------------------
Span visibility is QA metadata only. Images are NOT removed because a complete span or both structures are not visible.
Sequence membership is decided by circuit-run geometry / pass direction / AOI logic. DINO remains QA-only.
